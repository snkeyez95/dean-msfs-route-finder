# Claude's working notes — backup copies

These are **mirrors**, not the live files. The live ones live in `%USERPROFILE%\.claude`,
which git never sees — so a drive failure would take them with it. This folder is the backup.

Refresh with `node tools\sync-notes.js` (run before committing if the notes changed).
